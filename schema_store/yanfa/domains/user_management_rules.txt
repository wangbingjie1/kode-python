# 用户已确认的业务规则（构建本体时必须遵守）

## 规则 1: user vs platform_user
**类型**: 表关系
**问题**: 存在两个用户主表（user 和 platform_user），它们之间的关系和使用场景不明确
**用户确认**: user 是glbgpt 产品的用户，platform_user  是divino产品的用户表

## 规则 2: backup_disabled_blacklist_accounts
**类型**: 表用途
**问题**: 表名包含 'backup'、'disabled'、'blacklist' 三个概念，实际用途不明确
**用户确认**: blacklist 这个黑名单表在使用，其他的没有用

## 规则 3: platform_user_account.user_id
**类型**: 数据完整性
**问题**: 账户表的 user_id 缺少外键约束和非空约束
**用户确认**: platform_user_account 和user表 没有关系，是独立产品的表

## 规则 4: platform_user_wallet.private_key
**类型**: 数据一致性
**问题**: 私钥以明文形式存储在数据库中
**用户确认**: 这个字段没有使用

## 规则 5: user.email vs platform_user.email
**类型**: 数据完整性
**问题**: 邮箱字段缺少唯一性约束
**用户确认**: 的确有这个bug
